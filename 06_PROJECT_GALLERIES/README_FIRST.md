# Nebiyu Portfolio Project Gallery Assets

This package contains 48 individual project gallery images, 8 for each featured project:

* DegisSnap
* NAEP
* Nehas Digital Signage
* FSSS Limat POS
* Tibeb Market
* AradaCart

## Important accuracy rule

These images are AI generated concept UI visuals based on the planned features and portfolio direction.

They are NOT verified screenshots captured from the live applications.

Use them as:

* Concept UI
* Product vision visuals
* Case study gallery artwork
* Placeholder gallery images until real screenshots are available

Do not label them as "real production screenshots" or "proof of production."

For projects with real working applications, replace or supplement these images with actual captured screenshots whenever possible.

## Claude integration

Recommended destination:

public/images/projects/<project-slug>/gallery/

Use `gallery-manifest.json` for suggested titles and alt text.

The project detail gallery should support clicking an image to view a larger version.

Keep an explicit visual label such as "Concept UI" on these gallery items unless they are replaced by verified real screenshots.
