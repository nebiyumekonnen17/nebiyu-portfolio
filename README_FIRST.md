# Nebiyu Mekonnen Portfolio Starter Kit

This package is the source of truth for Claude to build Nebiyu Mekonnen's portfolio website.

Start with these files in this order:

1. `05_CONTENT/CLAUDE_BUILD_PROMPT.md`
2. `05_CONTENT/PORTFOLIO_MASTER_PLAN.md`
3. `05_CONTENT/CONTENT_AND_WRITING_RULES.md`
4. `05_CONTENT/site_content.json`
5. Review the visual references and real assets in folders 01 through 04.

## Important

The latest homepage mockup is:

`01_REFERENCE_UI/homepage_primary_reference.png`

Use it as the primary visual direction.

Do not invent live URLs, repository URLs, certifications, dates, employers, job titles, metrics, or project status.

Project cards must be clickable and open detailed project pages.

Only show a Live Project or Repository button when a verified URL exists in the content data.

The homepage should stay easy to scan. Detailed technical information belongs on project detail pages and the AWS experience page.
